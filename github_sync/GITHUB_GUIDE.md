## 1. Git 是什么？能吃吗？

**Git** = 一个**自动记笔记的小秘书** 📝

- 你每写一次代码，Git 就帮你拍一张**照片**📸
- 照片记录了**那一刻所有文件的样子**
- 哪天代码改坏了，可以**翻出老照片**回到之前的样子
- 就像游戏里的**存档**功能！

**比喻：** 写作文的时候，每改一版都复印一份保存。Git 就是帮你自动复印的那个小助手。

---

## 2. GitHub 又是什么？

**GitHub** = Git 的**云盘** ☁️

- 你的代码存在**自己电脑**上（这叫"本地"）
- GitHub 是**网上的仓库**（这叫"远程"）
- 两边可以**同步**——电脑上改了，上传到 GitHub；GitHub 上别人改了，你下载下来

**比喻：** 
- Git = 你家里的文件柜 📁
- GitHub = 银行保险柜 🏦
- 家里改完文件 → 复印一份放银行保险柜
- 这样就算家里着火了，银行还有备份！

## 3. 第一次连接 GitHub（只需要做一次）

> ⚠️ **在做之前，请先去 GitHub 网站注册一个账号！**
> 网址：https://github.com/signup

### 第一步：在 GitHub 网站上创建一个空仓库

1. 打开浏览器，登录 https://github.com
2. 点右上角的 **+** 号 → **New repository**
3. 在 **Repository name** 里输入仓库名字（比如 `Python_code`）
4. 别勾选任何东西，直接点最下面的 **Create repository** 绿色按钮
5. 你会看到一个页面，里面有二维码和网址，**先别关这个页面**

### 第二步：在 VS Code 里连接 GitHub

打开 VS Code 的**终端**（Terminal）——就是屏幕下面那个黑乎乎的窗口，然后**复制粘贴**下面的命令（一行一行来）：

```bash
# 第1条：告诉 Git 你的名字（改成你的 GitHub 用户名）
git config user.name "你的GitHub用户名"

# 第2条：告诉 Git 你的邮箱（改成注册 GitHub 用的邮箱）
git config user.email "你的邮箱@example.com"

# 第3条：连接 GitHub 仓库（把下面的地址换成你的）
#        👇 把"你的用户名"和"仓库名"改成你自己的
git remote add origin https://github.com/你的用户名/仓库名.git

# 第4条：把代码上传到 GitHub
git push -u origin main
```

> 💡 运行 `git push` 的时候，可能会弹出一个窗口让你登录 GitHub。
> **点"登录"→ 浏览器里登录 → 授权** 就行。

## 4. 每天怎么保存代码？

> **记住三个动作就够了：**
> 📂 打包 → 💾 拍照 → 📤 上传

### 方法一：用我帮你做的自动脚本（最简单！）

在 VS Code 的**终端**里输入：

```bash
python scripts/auto_git_sync.py
```

它会自动：
1. ✅ 把修改过的文件都收集起来
2. ✅ 拍一张快照（commit）
3. ✅ 上传到 GitHub（如果连好了）

### 方法二：手动操作（就 3 步）

在 VS Code 左边的活动栏，点这个图标：![分支图标](https://code.visualstudio.com/assets/icons/codicons/source-control.svg) **源代码管理**（或者按 `Ctrl+Shift+G`）

你会看到一个面板，上面显示所有修改过的文件。

**第1步：** 把鼠标移到 **更改** 两个字上面，点出现的 **+** 号（这叫"暂存所有更改"）
**第2步：** 在上面的输入框里写一句说明（比如 "修改了新闻功能"）
**第3步：** 点上面的 **✓ 提交** 按钮

## 6. 怎么只上传一个文件？

有时候你只改了一个文件，不想把所有东西都传上去。

### 方法一：在 VS Code 里操作

1. 按 `Ctrl+Shift+G` 打开源代码管理
2. 在 **更改** 列表里，**只把鼠标移到你想上传的那个文件上**
3. 点它旁边的 **+** 号（而不是点"更改"旁边的 +）
4. 写一句说明
5. 点 **✓ 提交**
6. 在终端输入 `git push`

### 方法二：在终端里操作

```bash
# 只添加这一个文件
git add 文件名.py

# 提交（记得写说明）
git commit -m "修改了xxx功能"

# 上传到 GitHub
git push
```

**举例：** 我只想上传 `show_news.py` 这个文件：

```bash
git add show_news.py
git commit -m "修改了新闻显示功能"
git push
```

## 7. 怎么把 GitHub 上的代码下载到电脑？

### 第一次下载（电脑上还没有这个项目）

这叫 **clone（克隆）**：

```bash
# 在你想放代码的文件夹里运行
git clone https://github.com/用户名/仓库名.git
```

### 更新代码（电脑上已经有一个了）

这叫 **pull（拉取）**：

```bash
git pull
```

> 💡 **记住：** 在你开始写代码之前，先 `git pull` 一下，确保拿到最新版本！

## 8. 怎么分享文件给朋友？

### 方法一：分享整个项目的链接

1. 打开 https://github.com/你的用户名/仓库名
2. 复制浏览器地址栏的网址
3. 发给朋友

### 方法二：分享单个文件

1. 打开 GitHub 上的仓库
2. 点进去你想分享的那个文件
3. 点右上角的 **Raw** 按钮
4. 复制浏览器地址栏的网址
5. 发给朋友

### 方法三：下载 ZIP 文件（不需要 Git）

1. 打开 GitHub 仓库页面
2. 点绿色的 **<> Code** 按钮
3. 点 **Download ZIP**
4. 得到一个压缩包，可以发给任何人

## 9. 怎么接受朋友分享的项目？

### 如果朋友分享的是 GitHub 仓库链接

在终端运行：

```bash
# 把链接换成朋友的仓库地址
git clone https://github.com/朋友用户名/仓库名.git
```

这会把整个项目下载到你电脑上。

### 如果朋友发的是 ZIP 文件

1. 把 ZIP 解压到你想放的文件夹
2. 在 VS Code 里点 **文件 → 打开文件夹**，选那个解压出来的文件夹

## 10. 代码改错了怎么回到之前的样子？

> **这是 Git 最牛的功能！** 就像游戏里的"读档"。

### 方法一：看看修改了哪些文件（还没保存时）

```bash
git status
```

会显示红色文字 = 修改过的文件

### 方法二：放弃修改，回到上一次保存的样子

```bash
# 放弃单个文件
git checkout -- 文件名.py

# 放弃所有修改
git checkout -- .
```

> ⚠️ **注意：** 这个操作会**丢失你还没保存的修改**，慎用！

### 方法三：回到之前某一次保存的版本

```bash
# 先看看有哪些历史版本
git log --oneline

# 会显示这样的记录：
# a1b2c3d 修改了新闻功能
# e4f5g6h 增加了定时任务
# i7j8k9l 初始版本

# 选一个你想回去的版本（用那串字母数字）
git checkout a1b2c3d
```

### 方法四：在 VS Code 里用鼠标操作（最简单）

1. 按 `Ctrl+Shift+G` 打开源代码管理
2. 点上面的 **...**（更多操作）
3. 选 **查看提交历史** 或 **分支**
4. 右键点击你想回去的那个版本
5. 选 **检出（Checkout）**

## 11. 自动同步脚本怎么用？

我给您写了一个自动小助手，在 `scripts/auto_git_sync.py`。

### 手动运行

在终端输入：

```bash
python scripts/auto_git_sync.py
```

脚本会自动：
1. 📂 收集所有修改过的文件
2. 💾 拍照保存（commit）
3. 📤 上传到 GitHub（如果已经连好了）

### 设置定时自动运行（每天自动同步）

想让电脑**自己每天自动上传**？可以设置 Windows 任务计划程序：

1. 按键盘上的 `Win` 键，搜索 **任务计划程序** 并打开
2. 右边点 **创建基本任务**
3. 名称填：`自动同步代码`
4. 触发器选：每天 → 设置时间（比如早上9点）
5. 操作选：**启动程序**
6. 程序或脚本填：`python`
7. 参数填：`scripts/auto_git_sync.py`
8. 起始于填：`e:\2026_AgentStudy\Python_code`
9. 点完成

这样每天电脑就会自动帮你把代码同步到 GitHub 啦！🎉
