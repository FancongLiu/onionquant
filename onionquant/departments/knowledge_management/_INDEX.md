## 天才Agent编制
- **首席知识架构师** — 设计知识图谱结构
- **图谱维护员** — 定期更新各部门知识图谱

## 知识管理规则

### 每条知识必包含
- id / topic / type / summary / conclusion / confidence / source

### 知识类型
- 📄 论文 → 学术来源
- 🛠️ 工具 → 开源项目/API
- 📊 方法 → 可复现方法论
- 💡 策略 → 具体交易策略
- 🚫 反模式 → 验证失败的方案
- 📋 结论 → 经过辩论确认的结论
- 🏗️ 架构 → 系统设计决策

### 更新规则
- 每个部门每周更新自己的知识图谱
- 知识管理部每月汇总公司总图
- 任何重大发现 → 24小时内录入
