### 1.1 Qlib (Microsoft)

| **语言** | Python |

| **License** | MIT |

**核心功能：**
- AI驱动的全流程量化平台（数据处理->模型训练->回测->组合优化->执行）

**美股适合度：7/10**

| 指标 | 数据 |
|------|------|
| **GitHub** | https://github.com/AI4Finance-Foundation/FinRL |

| **语言** | Python |

**核心功能：**

- 模块化设计：FinRL-Meta(数据/环境) -> FinRL(训练) -> ElegantRL(算法) -> FinRL-X(生产)

**优势：**
- 强化学习量化领域标杆项目

**劣势：**
- DRL训练不稳定，超参数敏感
- 回测框架相对简单（不如Qlib专业）
- 从研究到实盘仍有距离
- 文档分散在多个仓库

**美股适合度：8/10**
- 原生支持Yahoo Finance美股数据
- DRL可用于美股做市、执行优化
- FinRL-X支持多账户美股交易

**综合评分：8.0/10**（AI/ML领域最高分）

## 6. 技术选型建议

### 核心推荐策略

基于以上调研，建议采用 **"核心平台 + 垂直扩展"** 的多层架构：

```
         ┌─────────────────────────────────────────────┐
         │            OpenBB Terminal                  │
         │     (数据中台 - 100+数据源 / MCP协议)        │
         └────────────────────┬────────────────────────┘
                              │
         ┌────────────────────┼────────────────────┐
         │                    │                    │
         ▼                    ▼                    ▼
   ┌──────────┐      ┌──────────────┐     ┌────────────┐
   │  Qlib    │      │ VectorBT     │     │  LEAN /    │
   │(AI研究)  │      │(参数优化/因子)│     │NautilusTrdr│
   └──────────┘      └──────────────┘     │(实盘交易)  │
                                           └────────────┘
         │                    │                    │
         ▼                    ▼                    ▼
   ┌──────────┐      ┌──────────────┐     ┌────────────┐
   │  FinRL   │      │  Kronos      │     │  FinGPT    │
   │ (RL训练)  │      │ (K线预测)    │     │ (情感分析)  │
   └──────────┘      └──────────────┘     └────────────┘
```

### 具体推荐

| 层级 | 首选方案 | 备选方案 | 理由 |
|------|---------|---------|------|
| **数据中台** | OpenBB Terminal | yfinance | OpenBB支持100+数据源 + MCP协议 + AI Copilot |
| **AI研究平台** | Qlib (RD-Agent) | 自研 | RD-Agent自动因子挖掘，AI能力最强 |
| **RL训练** | FinRL-X | FinRL | FinRL-X同时支持ML+DRL+LLM |
| **LLM情感分析** | FinGPT v1.0 | - | 情感分析准确率82.1%，成本低 |
| **K线预测** | Kronos | - | AAAI 2026论文，120亿K线预训练 |
| **参数优化/因子** | VectorBT | Qlib | 向量化回测性能极高 |
| **回测引擎** | LEAN / NautilusTrader | VectorBT | 工业级事件驱动 vs 高性能向量化 |
| **投组优化** | PyPortfolioOpt | Riskfolio-Lib | 简洁API vs 丰富风险度量 |
| **组合风控** | gs-quant | - | 高盛25年金融工程积累 |
| **实盘交易** | LEAN (QuantConnect云) | NautilusTrader | 美股数据开箱即用 vs 极致性能 |
| **前沿探索** | TradingAgents | AI Hedge Fund | 多智能体LLM交易是2026年最大趋势 |

### 优先级排序

**P0（立即采用）：** OpenBB Terminal, yfinance, Qlib, VectorBT
- 这4个工具构成数据 + AI研究 + 回测的基础架构

**P1（1-2月内集成）：** FinRL-X, Kronos, FinGPT, LEAN
- AI/ML能力增强 + 生产级回测

**P2（3-6月评估）：** TradingAgents, AI Hedge Fund, NautilusTrader
- 前沿项目，需进一步验证可靠性

**P3（持续关注）：** Riskfolio-Lib, gs-quant, PyPortfolioOpt
- 在特定场景下补充使用
