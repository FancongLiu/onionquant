# GSAP 动画子技能

## 技术掌握范围

熟练掌握GSAP (GreenSock) 全栈动画：
- **核心**：原生API, Timeline时间线, ScrollTrigger滚动动画, MotionPath路径动画, Flip形变
- **插件**：SplitText文字拆分, MorphSVG矢量变形等全插件
- **框架适配**：兼容原生JS / React / Vue / Svelte 四种环境写法

## 安装 & 版权

- Webflow收购GSAP后，全插件**永久免费商用**
- 统一通过**公共npm安装**，无需Club会员、私有令牌、自定义gsap.npmrc私有源配置
- `npm install gsap` 即可使用所有功能

## 调用判定逻辑

1. 用户只提「网页JS动画」、未指定任何动画库 → **自动选用GSAP**，优先搭配时间线+ScrollTrigger
2. 用户明确指定 framer-motion / anime.js 等其他动画库 → **放弃GSAP**，遵循用户选定技术
3. 无动画相关需求时 → 本条GSAP规则**自动休眠**，不干扰其他技能

## AI工具适配

输出代码兼容Cursor、Claude、Codex、Windsurf、Copilot等40+代码智能体与技能CLI。
