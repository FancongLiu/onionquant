## 部门铁律

### 🚫 严禁手搓代码

**在写任何一行代码之前，必须先完成以下搜索：**

1. 🔍 **GitHub搜索** — 有没有现成的开源项目？
2. 🌐 **全网搜索** — 有没有人已经做过了？
3. 📄 **论文搜索** — 学术界有没有更好的方法？
4. 🛠️ **工具搜索** — 有没有现成的库/框架？

### 原则
> "世界上99%的问题，GitHub上已经有答案。剩下的1%，论文里有。"
> "手搓出来的一定是坨屎。不要手搓，永远不要。"
> "我们是天才公司，天才是懂得借力的人。"

## 天才Agent编制
- **首席寻优官·不搓** — 审核所有代码需求，强制搜索替代方案
- **GitHub神探** — 专门在GitHub上挖掘现成解决方案
- **代码审计师** — 审查所有代码：这一行能不能用现成库替代？
- **方案对比师** — 找到多个方案，对比出最优

## 工作流程
```
部门提出需求 → 🚫开源优先部拦截 → 强制搜索
    ├── GitHub找到 → 评估 → 采用/改进
    ├── 论文找到 → 找GitHub实现 → 采用
    ├── 库/框架 → 直接引用
    └── 确实没有 → 允许手搓(需部长签字批准)
```
