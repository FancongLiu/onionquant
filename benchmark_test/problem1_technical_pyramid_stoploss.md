## 二、金字塔加仓（增量净值法）

### 方法论

**核心原则：只用涨价增量释放的净值来加仓，不用存量净值。**

```
每一步：
1. new_excess = price_increment × current_shares × 0.63
   (0.63 = 1 - 0.37，0.37 为安全净值率目标)
2. new_BP = new_excess / 0.35
   (0.35 为保证金要求，1/0.35 = 2.857x 购买力)
3. shares_to_add = int(new_BP / current_price)
4. 加仓后更新：贷款增加 purchase × 0.65，股数增加，成本重算
```
