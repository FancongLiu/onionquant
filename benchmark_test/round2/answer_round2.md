# 题三：MU 独跌之谜 + 周一操作方案

## 一、周五 MU 独跌：三个独立原因

### 原因 1：板块内部轮动——NAND 抽血 DRAM

这是最根本的原因。

| | NAND 阵营 | DRAM 阵营 |
|------|------|------|
| 标的 | SNDK +5.2%, WDC +6.1%, STX +6.3% | **MU -1.4%** |
| 供给 | 收缩 -5%，零新产能 | 扩张 +10%，三星扩 20 万片/月 |
| 涨价 | Q2 +70-75% QoQ | Q2 +58-63% QoQ |
| AI 叙事 | 推理驱动企业 SSD | 训练驱动 HBM |

资金在追逐更稀缺的 NAND、抛弃供给在扩张的 DRAM。同一板块内出现了跷跷板效应。

### 原因 2：周四暴涨后的获利回吐

MU 周四（6/12）+11.7%，是半导体中涨幅最大的。次日后半段获利盘涌出，属于正常的回调消化。SNDK 周四也涨了 +14.5% 但周五继续涨——因为 NAND 的买盘更持续。

### 原因 3：FOMC 前避险 + 没有新催化

INTC 有 BofA 双级上调（$135 PT）+ Google TPU 3M+ 订单两大新鲜催化。SNDK 有分析师三连升级（BofA $2,100 + Mizuho $2,200 + Cantor $2,900）。**MU 最近的新催化是 6/24 财报（还有 12 天），中间是真空期。** FOMC 周二，不确定性在前，资金会先撤出没有即时催化的高杠杆持仓。

### 没有发生的事

周五没有 MU 的负面新闻。HBM4 分配争议是 2 月旧闻。CEO 卖出是 10b5-1 计划。**不是利空驱动的下跌，是资金选择驱动的下跌。**

## 二、周一（6/16）操作方案

### 当前状态

```
109 股 @ $955.62，MU $982
浮盈 +$2,875，净值 $38,500，杠杆 2.84x，融资率 99.49%
```

### 核心判断

**FOMC 是本周的变量。MU 财报是下周的变量。** 周一本身没有事件，但周二的 FOMC 会在周一产生提前避险行为。

### 周一操作

| 场景 | 操作 |
|------|------|
| MU 开盘在 $980 以上 | **卖 10 股**（~$9,820），净值率升到 ~36%，杠杆降到 2.5x |
| MU 开盘在 $960-980 | 不操作，观察 |
| MU 跌破 $955（成本） | **卖 15 股**，杠杆降到 2.2x |

### 周一不要做的事

- 不要加仓（FOMC 前不加杠杆）
- 不要因为"上周五跌了所以周一一定会反弹"而追买
- 不要清仓（MU 的逻辑没坏，只是短期无量能支撑）

### 设止损

```
SELL 109 MU STOP 930 GTC
```

$930 破了（融资率 ~122%，离 135% 强平有空间）→ 清仓。FOMC 前就挂在系统里。

## 三、6/24 财报前的仓位管理

### 时间线

| 日期 | 事件 | 仓位目标 |
|------|------|------|
| **周一 6/16** | FOMC 前夜 | **降到 99 股**（卖 10 股，杠杆 2.5x） |
| **周二 6/17** | FOMC 决议 | 不操作。如果砸盘 → 不卖；如果反弹 → 不动 |
| **周三-周五 6/18-20** | FOMC 后消化 | 如果 MU 回到 $1,000+ → 再减 15 股到 84 股 |
| **周一 6/23** | **财报前一天** | **强制减到 50-60 股**，杠杆 1.5x 以下 |

### 为什么 6/23 必须减仓

MU 财报预期 +268% YoY 营收增长。定价完美。如果 MU 重演 AVGO 的 beat→crash 模式（-15%）：
- 50 股 × $1,000 × -15% = -$7,500，净值从 $38,500 → $31,000（扛得住）
- 109 股 × $1,000 × -15% = -$16,350，净值从 $38,500 → $22,150（扛不住，可能触发强平）

**差价是账户的生死线。**

### 完整止损线（周一挂上）

```
GTC: SELL 109 MU STOP 930
```

周一开盘卖 10 股后更新为：

```
GTC: SELL 99 MU STOP 930
```

## 总结

MU 周五独跌不是基本面出了问题，是板块内资金从 DRAM 流向 NAND + 周四暴涨后获利回吐 + FOMC 前避险。周一先卖 10 股降杠杆，周二 FOMC 不做任何操作，6/23 财报前必须减到 50-60 股。
