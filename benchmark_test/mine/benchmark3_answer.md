### 1.4 ⚠️ 对题目前提的修正（诚实纠偏）

题目标题说"**唯独 MU 单独走弱**"。真实数据显示需要修正：

1. **6/12 当天**：MU −1.43% 确实是 5 只里**最弱**，但**并非"只有 MU 跌"**——AVGO 也跌（−0.91%）。准确说法是"MU 与 AVGO 双双走弱，NVDA/INTC/SNDK 上涨"。
2. **周累计（6/9→6/12）**：MU **+4.89%**，反而**跑赢 NVDA（−1.44%）和 AVGO（−2.57%）**。真正"分化"的本质是：**INTC（+15%）和 SNDK（+20%）暴涨，把 MU 衬托得相对弱**，而不是 MU 绝对走弱。
3. **更关键的背景**：MU 6/3 在 $1,079.57 见顶后，**到 6/9 跌到 $854.35（−20.8%）**，6/11 才反弹 +11.66%。所以 6/12 的 −1.43% 是**见顶暴跌后的反弹中的小回吐**，不是"突然单独走弱"。

**结论：题目"MU 单独走弱"的叙事部分成立（6/12 当天 MU 确实最弱），但"单独"二字不准确（AVGO 同弱），且忽略了 MU 周累计跑赢 NVDA/AVGO 的事实。**

## 第二部分：问题一 —— 归因分析

### 2.1 真凶：Broadcom 6/4 财报/AI 指引，而非 6/12 当天的事

**核心发现：导致 MU 走弱的催化剂不在 6/12，而在 6/4。** 传导链如下：

```
6/4 Broadcom 财报：AI/custom ASIC 销售指引不及预期（CNBC/Yahoo 证实）
   │  AVGO 当日 −14% 至 ~$411
   ▼
市场重新审视 HBM 需求叙事：
   │  "如果超大厂自研 ASIC（AVGO 模式），NVIDIA GPU 增长放缓，
   │   那 HBM（MU 核心增长引擎）的需求会不会见顶？"
   ▼
6/4–6/5 MU 暴跌：6/4 −6.5%（premarket），6/5 续跌
   │  从 6/3 顶 $1,079.57 → 6/9 底 $854.35，累计 −20.8%
   ▼
6/9 锤子线（低 854.35，收 935.89）+ 6/11 反弹 +11.66%
   │  → 技术性修复，但叙事疑虑未消
   ▼
6/12 MU −1.43%：反弹乏力，"卖预期"（6/24 财报前获利了结）
   │  + AVGO 同弱（−0.91%）= "HBM 受疑"叙事持续压制 MU
   ▼
同期 INTC +6.51%（Google TPU 订单 + BofA 双级上调）
   SNDK +5.24%（NAND sold-out，与 HBM 叙事无关）
   → 资金从"DRAM/HBM 疑虑"轮动到"代工期权(INTC)+NAND 确定性(SNDK)"
```

### 2.3 一次性事件 vs 趋势性转折？

| 情景 | 概率 | 理由 |
|---|---|---|

## 第三部分：问题二 —— 下周一（6/15）操作决策

### 3.1 先处理融资危险水位（第一优先级）

**现状重算**（用 6/12 收盘 $981.61 作为最新价）：
```
持仓 109 股 × $981.61 = $107,005  (市值)
净值 $38,500 → 贷款 = 107,005 − 38,500 = $68,505
杠杆 = 107,005 / 38,500 = 2.78x
融资比率 ≈ 2.78 / 2.857 = 97.3%
```
**比题目假设的 99–105% 略好（因为 MU 已从 $1,000 跌到 $981.61），但仍贴着危险线。**

融资比率定价模型（恒等式）：`E(P) = 109P − 68,505`

| 融资比率 | 含义 | 触发价 |
|---|---|---|
| 100% | 危险线 | $981.61 × (97.3/100) ≈ **$954**（再跌 $27 就撞） |
| 110% | 止损一 | ≈ **$905** |
| 135% | 强平 | ≈ **$820** |

**MU 再跌 2.7%（到 $954）就撞危险线。** 缓冲极薄。

### 3.2 操作指令（具体到股数和价位）

#### 🚨 第 0 步：周一开盘立即主动减仓（最高优先级）

**指令**：**市价单卖出 20 股 MU**（或限价 $975–985 卖），开盘 5 分钟内执行。

**算账**（假设卖价 $980）：
```
卖 20 股 × $980 = $19,600 回笼
新持仓 89 股 × $980 = $87,220
新贷款 = 68,505 − 19,600 = $48,905
新净值 = 87,220 − 48,905 = $38,315（权益几乎不变，回笼现金还了贷款）
新杠杆 = 87,222 / 38,315 = 2.28x
新融资比率 = 2.28 / 2.857 = 79.7%  ✅
新危险线(100%) = 89P/(89P−48,905) = 2.857 → P ≈ $882
新强平价(135%) ≈ $770
```
**这一步把融资比率从 97.3% 砸到 79.7%，危险线从 $954 下移到 $882，强平价从 $820 下移到 $770。** 凭空多出 $72 强平缓冲。这是整个方案里确定性最高、性价比最高的一步。

> **为什么是 20 股不是 10 股**：6/24 财报在即（8 个交易日后），财报 binary 事件 ±15~25%。在 97.3% 融资水位带满仓进财报 = 赌博。减 20 股是"用 18% 仓位换 17.6 个百分点的融资安全垫"，极其划算。

#### 📋 减仓后设三道止损（GTC 条件单，89 股基础）

| **止损二** | **$882**（新危险线 100%） | 卖 20 股 → 54 股 | 融资率撞危险线，强制降杠杆 |
| **止损三** | **$820**（6/9 绝对低点 $854 下方） | 清至 30 股 | 双底破位，趋势崩塌，保核心仓 |

### 3.3 两种情景应对

#### 情景 A：MU 周一继续下跌（跌破上周四低 $960.19）

| 触发价 | 动作 | 逻辑 |

**情景 B 核心原则**：财报前**最多**加回 8 股（从 89 → 97），**不超过减仓前的 109 股**。因为 6/24 财报是 binary 事件，财报前不宜恢复满仓杠杆。
