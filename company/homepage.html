Project

核心项目 · OnionQuant

OnionQuant 是一套基于 Multi-Agent 层级架构的自动化数据分析与研究平台。 AI Agent 按职能组织为类公司层级结构，CEO 负责任务分解与调度，各部门 Agent 并行执行， 从自然语言指令到分析报告的端到端自动化。

系统能力

  • Multi-Agent 协作引擎
    CEO Agent 接收自然语言指令 → 意图识别与任务分解 → 调度 15+ 部门 Agent 并行 Fork 执行 → 结果聚合。 支持任务优先级调度、死锁检测、超时熔断。
  • 自动化数据分析管道
    多源数据自动采集（yfinance · 舆情源 · WebSearch）→ Pandas 清洗标准化 → 统计分析与因子计算 → 可视化报告生成。Agent 自主选择分析工具链，全链路自动闭环。
  • LLM Agent 对话 & 工具调用
    LangChain Prompt 模板 + Tool Use / Function Calling。Agent 根据任务类型自主选择和组合工具。 上下文窗口管理 + 对话历史压缩 + 多轮意图追踪。
  • 知识图谱增强
    基于 NetworkX 构建知识图谱，关联标的 → 催化剂事件 → 供应链 → 宏观指标。 支持图遍历查询、影响传导路径分析、关联关系发现。
  • 实时双向通信
    微信企业 API AES-256-CBC 加密收发 + SSE EventSource 实时推送。 高频消息由 Python 脚本处理，复杂消息自动排队交 Agent 批量处理。
  • 自愈运维
    Watchdog 守护进程 30s 心跳检测 · 核心服务异常自动重启 · Cloudflare Tunnel 双通道冗余 · 开机自启 · 微信故障告警。
Work

工作经验

特灵科技亚太研发中心 · 数据分析与系统研发工程师
围绕暖通空调系统智能化，用 AI 和 Python 改造传统数据分析流程。

自动化数据处理管道

从 SharePoint 自动下载源数据 → Python 数据质量检查 → 统计分析 → 自动生成报告文件。 替代了原本手动 Excel 操作流程，将重复性数据处理工作自动化。

Tableau 自动化控制

通过 Python 修改 Tableau 工作簿 XML 文件（.twb），实现时间滑块自动调整、数据源刷新等操作。 使 Tableau 报表可以跟随数据管道自动更新，无需人工介入。

AI 会议纪要 → 任务提取

将会议录音/脚本输入 LLM，自动提取为结构化的 To-Do List：每条任务含描述、提出人、执行人、 上下文摘要。AI 根据历史任务优先级模式自动预判新任务优先级。

语音/聊天 → 结构化工时记录

将非结构化的语音输入或聊天记录，通过 LLM 语义解析转换为结构化的工时表格， 自动提取任务描述、耗时、项目归属等字段。

AI 驱动的工作辅助系统

独立开发了一套个人工作辅助系统，集成了上述自动化流程，通过 Web 前端统一管理：

  • Task Tracker 任务管理
    每条任务有状态流转（待开始 → 进行中 → 已完成）和优先级标记。 AI 学习历史任务的优先级选择模式，对新录入任务自动推荐优先级。
  • Deep Research 式的研究分析
    参考 OpenAI / DeepSeek Deep Research 的多步迭代架构（Plan → Search → Analyze → Synthesize → Reflect 循环）， 实现了自动化数据研究流程：识别信息缺口 → 选择数据源 → 采集分析 → 综合报告，多轮迭代直至覆盖研究目标。
