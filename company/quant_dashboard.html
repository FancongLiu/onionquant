🎓 量化入门：5分钟看懂这个面板
即使你完全不懂量化交易，下面的引导也能让你快速上手。每个数据旁边都有 💡 这是什么？ 按钮，点击就能看到通俗解释。顶部还有"一句话总结"，把复杂的数字翻译成人话。
🔢 第1步
先看"一句话总结"面板
页面顶部有个总结，用红/黄/绿灯告诉你当前策略好不好。绿色=继续持有，黄色=需要关注，红色=可能出问题。
📈 第2步
看净值曲线 (Equity Curve)
这条线往上走=赚钱，往下走=亏钱。红色阴影面积=最惨时亏了多少。如果线长期往上且波动不大，就是好策略。
🔥 第3步
看因子热力图 (Factor Heatmap)
绿色=因子在帮你赚钱，红色=因子在亏钱。找"长期稳定偏绿"的因子——那些是真正有效的信号。
🛡️ 第4步
看风险指标 (Risk Metrics)
Sharpe>1.0算合格，>2.0算优秀。最大回撤<-10%要注意。VaR告诉你"95%的情况下一天最多亏X%"，帮你做仓位管理。
🏆 第5步
比策略 (Strategy Comparison)
多策略横向对比——Sharpe高+回撤小=最优。别只看收益，回撤和夏普比收益更重要。
📖 第6步
查术语表 (Glossary)
页面底部有中英文术语表，所有量化名词都有解释。看到不懂的词就往下翻。
💡 核心心态：量化交易不是预测未来，而是用统计学方法找到概率上占优的策略。没有100%准确的信号，只有长期来看期望值为正的策略。Sharpe=1.0意味着每冒1块钱风险，大约赚回1块钱超额收益——这已经比大部分散户强了。

📈 净值曲线 (Equity Curve) loading...

净值曲线 = 你的钱随着时间的变化图
怎么看：线往上走 = 策略在赚钱；线往下走 = 策略在亏钱。红色阴影区域是"回撤"——从上一个高点跌了多少。
关键指标：斜率越陡 = 赚钱越快。曲线越平滑 = 风险越低。大起大落 = 高风险。
新手关注：如果这条线长期往上且没有大幅跳水，就是好策略。

🔥 因子热力图 (Factor Heatmap)

因子 = 预测股票涨跌的信号变量
怎么看：每一行是一个因子（如"动量"），每一列是一个交易日。颜色越绿 = 该因子当天预测越准（IC>0），越红 = 预测越差（IC<0）。
关键指标 IC (Information Coefficient)：因子值与未来收益的相关性。|IC|>0.02 算有用，|IC|>0.05 算优秀。
新手关注：找"长期稳定偏绿"的因子——那些是真正能赚钱的信号。

🛡️ Risk Metrics

风险指标帮你回答："这个策略最惨会亏多少？值得冒这个险吗？"
Sharpe > 1.0 = 合格，> 2.0 = 优秀。衡量"每冒1元风险赚多少超额收益"。
Max DD (最大回撤) = 从最高点跌到最低点的最大幅度。例如 -8.7% 意味着历史上最惨时亏了8.7%。这是你最需要关心的数字。
VaR 95% = 95%概率下一天最多亏X%。例如 VaR=-1.43% 意思是：100天里大约95天亏损不超过1.43%。
Volatility (波动率) = 15-25%正常，>40%高波动。波动大=不一定是坏事，但你得能承受。
新手黄金法则：先看Max DD——你能不能接受这个亏损幅度？再看Sharpe——赚钱效率够不够高？

📊 Portfolio Optimization

loading...
组合优化 = 决定每个股票买多少。不是简单平均分配，而是用数学方法找到最优配比。
MV (均值方差)：经典方法，在收益和风险之间找最优平衡。缺点是对输入参数敏感。
Risk Parity (风险平价)：让每个资产贡献相同风险。比MV更稳健，回撤通常更小。
HRP (分层风险平价)：用机器学习聚类股票，相关性高的归一组再分配。目前最先进的静态分配方法之一。
BL (Black-Litterman)：让你把自己的判断("我觉得NVDA会跑赢")融合进数学优化。
Kelly (凯利公式)：赌场用的公式——如果你知道胜率和赔率，每次该下注多少。适合有明确信号的策略。
新手推荐：先看 Risk Parity —— 最稳健，不易出错。熟练后再尝试其他方法。

🏆 Strategy Comparison loading...

不同策略横向对比，帮你选最优。
Sharpe = 最重要的指标，越高越好。>1.0算及格，>2.0算优秀。
Return (收益率) = 不能只看这个！高收益可能来自高杠杆或高波动。
MaxDD (最大回撤) = 绝对值越小越好。收益相近时选回撤最小的。
Win% (胜率) = 交易成功的比例。>50%算好，但胜率低也可能赚钱（如果赔率够高）。
新手选策略秘籍：Sharpe最高 + MaxDD最小 = 最佳选择。⭐标记的就是Sharpe最高的策略。

📖 术语表 Glossary (EN/CN) 收起 ▲

Factor / 因子A variable that predicts stock returns预测股票收益的信号变量，如动量、价值、波动率
IC (Information Coefficient)Spearman correlation between factor values and forward returns因子值与未来收益的斯皮尔曼相关系数，衡量因子预测能力。>0.02为好，>0.05为优秀
IC IR (Information Ratio)Mean(IC) / Std(IC) — measures signal consistencyIC的均值除以标准差，衡量信号稳定性。>0.5为好
Sharpe Ratio / 夏普比率(Return - RiskFree) / Volatility — risk-adjusted return每单位风险带来的超额收益。>1.0为合格，>2.0为优秀
Sortino Ratio / 索提诺比率Like Sharpe but only penalizes downside volatility只惩罚下行波动的夏普改进版，更适合不对称收益分布
Max Drawdown / 最大回撤Largest peak-to-trough decline in equity curve净值从最高点到最低点的最大跌幅，衡量最坏情况下的亏损
VaR 95% (Value at Risk)95th percentile worst daily loss — "we are 95% sure we won't lose more than X in a day"95%置信度下一天最多亏多少。例如VaR=-1.43%表示95%的情况下日亏损不超过1.43%
Calmar Ratio / 卡尔玛比率Annual Return / Max Drawdown — return per unit of worst pain年化收益除以最大回撤，衡量每单位"最大痛苦"换来的收益
Volatility (Ann.) / 年化波动率StdDev of daily returns × sqrt(252) — annualized price swing日收益标准差×√252，衡量价格波动幅度。15-25%为正常，>40%为高波动
Momentum / 动量因子Past winners tend to keep winning (Jegadeesh-Titman 1993)过去涨的股票未来一段时间继续涨。学术验证最强的因子之一
Reversal / 反转因子Short-term losers rebound (1-5 day horizon)短期(1-5天)跌太多会反弹。与动量互补，不同时间尺度
Value Factor / 价值因子Cheap stocks (low P/E, P/B) outperform expensive ones (Fama-French 1992)便宜的股票长期跑赢贵的。账面市值比(BP)和盈利市值比(EP)是经典指标
Ledoit-Wolf ShrinkageStatistical method to improve covariance estimation by shrinking toward a structured target通过向结构化目标收缩来改进协方差估计的统计方法，减少估计误差
Walk-Forward CV / 前向验证Time-series cross-validation that respects temporal order (no peeking at future)尊重时间顺序的交叉验证方法，绝不用未来数据训练（防前视偏差）
Barra Risk ModelIndustry-standard multi-factor risk model decomposing total risk into systematic + specific行业标准的多因子风险模型，将总风险分解为系统性风险+特质风险
Almgren-Chriss ImpactSquare-root market impact model for estimating trade cost before execution平方根市场冲击模型，用于在交易前估计大单对价格的影响
