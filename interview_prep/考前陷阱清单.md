# 考场 10 分钟速查 — 答错率最高的 10 个坑

## SQL（70% 的人会踩）

### 1. WHERE vs HAVING（最大陷阱）
```
WHERE  → 筛原始行（一行的值）
HAVING → 筛分组后（计算结果）
```
- `WHERE country = 'India'`  ✅ 原始值用 WHERE
- `HAVING COUNT(*) > 3`      ✅ 计算结果用 HAVING
- `HAVING membership = 'gold'` ❌ 这么写一定错！

### 2. 语法顺序不能乱
```
SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY
```
GROUP BY 在 HAVING 前面，别写反。

### 3. 聚合函数不能放 WHERE 里
```sql
WHERE COUNT(*) > 5    -- ❌ 报错
HAVING COUNT(*) > 5   -- ✅
```

### 4. JOIN 之后列名加表名
```sql
ON customers.customer_id = orders.customer_id   -- ✅
ON customer_id = customer_id                     -- ❌ 数据库不知道你在说哪个
```

### 5. 字符串用单引号，等于用一个等号
```sql
WHERE country = 'India'    -- ✅
WHERE country = "India"    -- ❌
WHERE country == 'India'   -- ❌ 这是 Python 写法
```

## Python

### 6. for 循环直接拿元素，不是下标
```python
for n in nums:    # n 就是值，不是索引
    print(n)       # ✅
    print(nums[n]) # ❌ C 语言思维
```

### 7. 字典方法全加 s
```python
d.values()   # ✅  不是 d.value()
d.items()    # ✅  不是 d.item()
```

### 8. str 是内置函数，别当变量名
```python
for w in words:   # ✅
for str in words: # ❌ 覆盖了内置函数
```

### 9. set 用 add，list 用 append
```python
my_set.add(x)       # ✅
my_list.append(x)   # ✅
```

### 10. 改原列表用 range(len)，只读直接 for
```python
for i in range(len(a)):   # 要修改 → 用索引
    a[i] = ...
for x in a:               # 只读 → 直接 for
    result.append(x)
```
