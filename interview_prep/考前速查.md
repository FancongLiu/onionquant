# Python 考前速查 — 核心记忆点

## 1. 遍历（你最容易卡的地方）

```
字符串 = 字符列表 = 可以直接 for 遍历
for c in "hello":   # c = 'h','e','l','l','o'
for n in [1,2,3]:   # n = 1, 2, 3
```
⚠️ **Python 不需要下标！** 不用写 `nums[i]`，直接用 `n`。

## 2. 字典 = 下标变成字符串的数组

```python
d = {}           # 空字典
d["h"] = 1        # 设值
d["h"] = d["h"] + 1  # 值+1
if "h" in d:      # 判断键是否存在
```

## 3. 五个核心操作

| 操作 | 代码 |
|------|------|
| 建空列表 | `result = []` |
| 建空字典 | `d = {}` |
| 加到列表 | `result.append(x)` |
| 字典设值 | `d[key] = value` |
| 字典取值 | `d[key]` |
| 判断存在 | `if x in list:` 或 `if key in dict:` |
| 排序返回 | `sorted(result)` |

## 4. 常见坑

- `set` 用 `add`，`list` 用 `append` — 别搞混
- 字符串遍历直接 `for c in s`，不是 C 的 `s[i]`
- 单引号 `'a'` 和双引号 `"a"` 一样，选一个用

## 5. 判断奇偶

```python
n % 2 == 0  → 偶数
n % 2 != 0  → 奇数
```

## 6. 字典常用方法

```python
d.keys()    → 所有键
d.values()  → 所有值 （注意 s）
d.items()   → 所有键值对，如 ("a", 1) （注意 s）
max(d.values()) → 最大值
```
⚠️ `max` 是内置函数，不要用它做变量名！用 `max_val` 代替。

## 7. 我的常见错误

- `str` 是内置函数，不要当变量名 → 用 `w`, `s`, `c`
- `.value()` ❌ → `.values()` ✅（加 s，返回所有值）
- `.item()` ❌ → `.items()` ✅（加 s，返回所有键值对）
- `pass` 不需要出现在正常代码里 → 用 `if not in`
- Python `for` 直接拿元素，不需要下标 `[i]`（和 C 语言不一样！）

## 8. 改原列表 vs 建新列表

```python
# 建新列表（90% 的题用这个）
result = []
for x in old_list:
    result.append(处理过的 x)

# 改原列表（需要用 range(len)）
for i in range(len(old_list)):
    old_list[i] = 处理过的 old_list[i]
```
⚠️ `for x in list` 拿的是副本，不能用来改原列表

## 9. 字符串三个高频操作

```python
s.split()        → 按空格切成列表
s[::-1]          → 反转字符串（步长 -1 = 倒着走）
' '.join(list)   → 用分隔符粘回字符串
```

## 10. range(n) = 从 0 数到 n-1

```python
range(5)  → 0, 1, 2, 3, 4
for i in range(len(a)):   # i 就是索引 0, 1, 2...
```

## 11. SQL 核心

**语法顺序（绝对不能乱）：**
```
SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY
```

**Python → SQL 对照：**
```
for n in nums:         →  SELECT ... FROM 表
if n > 10:             →  WHERE 条件（原始行）
sorted(result)         →  ORDER BY 列
```

**关键差别：**
- `=` 不是 `==`
- 字符串 `'India'` 单引号
- 没有 `append`、没有 `return`

**WHERE vs HAVING（最大坑）：**
```
WHERE  → 筛原始行的值（如 WHERE country = 'India'）
HAVING → 筛分组后计算结果（如 HAVING COUNT(*) > 3）
HAVING membership = 'gold'  ← 这样写一定错！原始值用 WHERE
```

**AS = 给计算式起名（SELECT 和 FROM 里面都能用）：**
```sql
COUNT(*) AS cnt          -- 给计算结果起名叫 cnt
SELECT AVG(cnt) FROM (...) AS t    -- 给子查询那张表起名叫 t
```
⚠️ `FROM (子查询)` 后面必须加 `AS 名字`，语法硬要求

**JOIN = 两张表用公共列拼起来：**
```sql
JOIN 表B ON A.公共列 = B.公共列
-- 列名前加表名，避免混淆：customers.customer_id
```

**ON vs IN — 完全不同：**
```
JOIN ... ON ...      → 拼表条件
WHERE ... IN (...)   → "在这个列表里"
```

**子查询 = SELECT 里面套 SELECT：**
```sql
-- 括号里的先算，结果交给外面
SELECT ... FROM ... WHERE x > (SELECT AVG(...) FROM ...)
```
⚠️ `AVG(COUNT(*))` 聚合套聚合 → 一定报错！用子查询代替。

**SQL 大小写不敏感：**
`select` 和 `SELECT` 一样，编辑器变色只是配色，不影响运行。
